One-line pitch

End-to-end retrieval-augmented Q&A: ingest PDFs, Word, and text plus arXiv fetch; chunk with section-aware metadata; embed in ChromaDB; retrieve with rerank + cross-paper diversity; generate answers with mode-specific prompts and citations — FastAPI API + Next.js dashboard + Ollama (demo without cloud LLM keys).

What buyers get

  • Grounded answers with expandable source cards (title, section, chunk, distance).
  • Modes: general Q&A, compare, methodology, dataset map, reproducibility checklist.
  • Operations: /health/live (liveness), /health/ready (readiness for traffic), X-Request-ID on responses, optional API_KEY on /api/v1, CORS allowlist, gzip, baseline security headers, optional JSON logs.
  • Production-minded API behavior: honest deletes (404), arXiv error mapping (404 vs 502 vs 504), validated query filters.
