One-line pitch

Ingest PDFs, Word, and text; optional arXiv fetch; chunk with section-style metadata; ChromaDB vectors; retrieval with rerank and cross-paper diversity; answers from Ollama with mode-specific prompts and citations. FastAPI backend and Next.js dashboard.

What buyers get

  • Grounded answers with source cards (title, section, chunk, distance).
  • Modes: general Q&A, compare, methodology, dataset map, reproducibility checklist.
  • Ops: /health/live, /health/ready, X-Request-ID, optional API_KEY on /api/v1, CORS allowlist, gzip, security headers, optional JSON logs.
  • Solid API behavior: 404 on empty delete, arXiv errors mapped to sensible status codes, validated section filters.

Standing out from “top example” RAG portfolios

High-visibility public examples skew toward tutorial-complete, not procurement-complete. The same stacks appear in job posts: LangChain or LlamaIndex orchestration, Pinecone/FAISS/Weaviate, GPT-4 or Gemini, Streamlit or a thin Next wrapper. That is table stakes. DocuMind is positioned where serious clients look next: operability, retrieval discipline, and explicit acceptance hooks.
